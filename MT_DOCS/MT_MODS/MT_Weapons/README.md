## 1. Текущий дизайн и фичи

### 1.1. Ядро системы (Ручки и Лезвия)
- **4 базовые категории:** Ножи (`mtmw:knife`), Катаны (`mtmw:katana`), Одноручные топоры (`mtmw:onehandaxe`), Двуручные топоры (`mtmw:axe`).
- **18 визуальных ручек:** M9, Керамбит, Ямато и т.д. Статы одинаковые (0 урона без лезвия).
- **16 лезвий по категориям:** по 4 лезвия (T1–T4) на каждую категорию. Катана — 4 лезвия, совместимы со всеми ручками катан; нож — 4, со всеми ручками ножей; и так далее.
- **Один item лезвия — разные визуалы на ручках:** item-скрипт лезвия один на категорию/тир; меш, текстура и положение для каждой ручки задаются её `ModelWeaponPart`.
- **Лезвие — нативный `WeaponPart`:** `PartType = Blade`, крепится к ручке через `MountOn`, рендерится через `ModelWeaponPart` + `attachment Blade`.
- **Стойки** активируются только при наличии лезвия: семейный тег + `WeaponState.isComplete(item)` (защита от «катаны без клинка»).
- **`mtmw:handle`** — маркер ручки; семейные теги ставятся только на ручки.

### 1.2. Аттачменты и модификации (6 слотов, 37 предметов)
1. **Лезвие** — базовый урон и прочность (`HeadCondition`).
2. **Текстура** — 10 расцветок (Эмеральд, Рубин), уникальные эффекты (кислота, кровотечение).
3. **Обмотка** — выносливость и хват.
4. **Стержень** — уникальные перки (Серебро не даёт зомби встать, Кевлар не даёт ронять оружие).
5. **Амулет** — криты, удача.
6. **Подвес (Ножны)** — скорость доставания.

### 1.3. Гравировки (Engravings)
- Наносятся через интерфейс Т.
- Всегда дают и плюс, и минус (баланс).
- Лимит: 3 гравировки на ручку.

### 1.4. Уход за оружием
- **Кровь:** запах привлекает зомби, ускоряет ржавчину. Смывается водой.
- **Ржавчина:** если не смазывать маслом, снижает урон.
- **Заточка:** бафф урона на N ударов.
- **Оружейная стойка:** крафтовая мебель, останавливает ржавчину.

### 1.5. Интерфейс Т (3D-Инспектор)
- Позже. Клавиша T. Вкладки: Stats (трекер убийств, анимация осмотра), Repair, Attachments, Engravings, Journal.
- В вертикальном срезе UI Т нет: только ванильное контекстное меню установки/снятия.

### 1.6. Метательные ножи (отдельная категория)
- Свой навык (Дуэлянт), своя система прицеливания, подбираются с земли.

### 1.7. Текущий вертикальный срез
Цель — проверить нативно, без полного контента:
- тестовая ручка `MT_Katana_Test` + тестовое лезвие `MT_Attachment_Katana_Blade_Test`, разложенные по шаблонной структуре (`DATABASE` §10.2, §10.5.2);
- нативный `WeaponPart` + `ModelWeaponPart`;
- установка через `MTAttachWeaponPart` (без экипировки части/отвёртки) и снятие через ванильное меню, в том числе из сумок и вложенных контейнеров;
- исправленный визуал прикреплённого лезвия: модель с identity node transform, без суффикса `_Attached`, нормальный размер в руке и в 3D-превью (правила экспорта FBX — `DATABASE` §10.5.1);
- снятое лезвие как отдельный `weaponpart` в руке не рендерится: в инвентаре — только иконка, в мире — `WorldStaticModel = GunCase_Ground`; это ожидаемо, `ModelWeaponPart` работает только в составе ручки;
- отладочные логи через `MT_Debug`: `[Module - Weapon]` attach/detach, `[Module - Damage]` hit (`damageSplit`, HP до/после), `[Module - Stance]` stance-target; включаются опцией `DebugEnable` внизу страницы настроек, после разделителя;
- страница настроек принадлежит `MT_ModOptions.lua`; стойки и дебаг только регистрируют свои секции;
- save/load; MP-путь реализован, но в текущем срезе не проверен — это целевая платформа (`DATABASE` §10.6.1).

Гейт стойки реализован: тестовая ручка получила `mtmw:katana` и `mtmw:handle`, но стойку включает только `WeaponState.isComplete(item)` — то есть только при прикреплённом лезвии. Проверка: ручка без лезвия стойку не получает, снятие лезвия снимает маску.

Aim-маска: `MT_KatanaAim` временно использует `Bob_TAC` (отдельный клип катаны — TBD). Лог `stance-target` показывает `target`, `current`, `reason`, `aiming`, `attacking`, `busy` при каждой смене цели.

Срез намеренно **не** содержит 18 ручек, 16 лезвий, текстур, гравировок и UI Т. После проверки — наполнение контентом (18 ручек, 16 лезвий).

ID тестовых предметов переименованы; старые `MT_Test_*` больше не существуют. Для проверки нужен новый сейв или выдача новых `MT_Katana_Test` / `MT_Attachment_Katana_Blade_Test`.

# [MT] Zeds — README

> Фичи и roadmap. Технические детали — `MT_MODS/MT_Zeds/DATABASE.md`.
> Паттерн Java-патча Idle — `MT_03_KNOWLEDGE` §3.4.

**Файл:** `Patch_ZombieIdleState.java` (+ опционально `Patch_ZombieGroupManager.java`).

## 1. Возможности

- **Длинные пути зомби:** до 50 тайлов (`MAX_TRAVEL = 50`).
- **Экономия CPU:** `THINK_ODDS = 60` — 98% вызовов отсеиваются.
- **Меньше кучкования:** очистка `z.group` (смягчение, не решение).
- **Совместимость с `PZ_Optimization`:** `LongAdder`, `volatile float[]`.

**Фундамент готов:** зомби двигаются длинными путями, `group=0` в Idle, экономия FPS.

## 2. Roadmap

### 2.1. Этап 1: «Осмысленное» поведение (Idle State)
- [ ] Разделить зомби на роли при спавне (`ModData: WZ_Role`):
  - [ ] `Wanderer` — бродит по карте (текущее).
  - [ ] `Haunter` — привязан к зданию, ходит по дому.
  - [ ] `OldMemory` — стоит у плиты/телевизора, не реагирует, пока не подойдёшь вплотную.
  - [ ] `Sleeper` — спит, просыпается при шуме.
- [ ] `THINK_ODDS` в `SandboxVars` для каждой роли.
- [ ] Шанс атаки для `OldMemory` — параметр в `SandboxVars`.

### 2.2. Этап 2: Взлом и вход в дома
- [ ] При цели «зайти в здание» — искать дверь/окно.
- [ ] Если дверь заперта — `setThumpTarget()` + ломать.
- [ ] Если окно — бить или перелезать.
- [ ] Логировать «зомби вошёл в дом».

### 2.3. Этап 3: Собственный Merge/Группы
- [ ] Свой `WZGroup` на `ModData`, **не** ванильный `z.group`.
- [ ] Лидер группы — `WZ_IsLeader = true` (шанс 10%).
- [ ] Последователи копируют цель лидера с `randOffsetPacked`.
- [ ] Автослияние двух групп (`MergeDistance`).
- [ ] Роспуск, если лидер мёртв или ушёл далеко.
- [ ] Всё через `SandboxVars`.

### 2.4. Этап 4: Расширенный Idle State
- [ ] Разрешить `Haunter` заходить в здания.
- [ ] При неудаче — попробовать другое здание.
- [ ] При полном провале — вернуть микро-шаг.

### 2.5. Этап 5: Настройки (SandboxVars / ModOptions)
- [ ] `THINK_ODDS` (глобальный + по ролям).
- [ ] `MAX_TRAVEL`, `WANDER_CHANCE`, `TO_PLAYERS`, `HOME_RADIUS`.
- [ ] `OldMemoryAttackChance`, `MergeDistance`, `GroupSize`, `BreakDoors`.

### 2.6. Этап 6: Дополнительные фичи
- [ ] MP-синхронизация `transmitModData` для `WZ_Role`, `WZ_IsLeader`, `WZ_Followers`.
- [ ] Статистика (роли, группы, средний размер).
- [ ] Debug-режим (линии групп в F11).

# [MT] AutoHide (UI Hide NavBar) — README

> Фичи и TODO. Технические детали — `MT_MODS/MT_AutoHide/DATABASE.md`.

**Файл:** `MT_UI_Hide_NavBar.lua`

## 1. Возможности

- **Авто-скрытие левой панели** (NavBar) при бездействии.
- **Плавный заезд/уезд** через `getTimestampMs()` + Smoothstep.
- **Настройка радиуса «рамки»** (пиксели).
- **Время заезда/уезда** (сек).

## 1. Возможности

- **Функциональные чипы** всегда активны, пока установлены — тумблера нет. Цена функции = цена чипа.
- **App-чипы** тратят заряд, только пока приложение открыто.
- **Снятие ядра** с чипами заблокировано — неявная защита от сиротских чипов.
- **EMP-двигатель:** авто не перезапускается после EMP, сиротские локи гасят свет, кулдаун wall-clock.
- **HUD** — иконка часов + кольцо + батарейка (5 тиров, пульс <5%). ПКМ → настройки. При наличии ядра — тактический хотбар.
- **Тактический хотбар** — слоты, Drag&Drop, кулдауны, «нет батарейки», Hide/UnHide (v6), замок, полоса.

## 1. Возможности

- **Тактические сумки T1–T6:** апгрейд через крафт (T1 → T2 → … → T6).
- **Рекрафт с сохранением:** при крафте новая сумка автоматически надевается на персонажа, вещи и вода переносятся из старой.
- **Фляги:** отдельный путь — `hb:attachItem` (хотбар) + `copyFluidsFrom` для воды.
- **Кобуры/медсумки/патронташи:** аналогичная система апгрейда.
- **Две версии:**
  - `More Balance` — с ограничениями на предметы.
  - `No Item Restriction` — без ограничений.
